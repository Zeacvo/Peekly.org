# ДИЗАЙН-СИСТЕМА PEEKLY: КАНОНИЧЕСКАЯ ПАЛИТРА И ПРАВИЛА ВЁРСТКИ

На сайте действует **СТРОГИЙ МОНОХРОМНЫЙ СТИЛЬ (Apple-inspired Brutalism)**. 
Интерфейс строится ИСКЛЮЧИТЕЛЬНО на базе 4 основных цветов и 1 цвета вторичного текста:

1. **ЧЁРНЫЙ `#000000`** — Глобальный базовый фон страницы (`body`, `main`, подложки).
2. **СЕРЫЙ `#090909`** — Фон карточек, блоков и контейнеров, чтобы они слегка отделялись от чисто чёрного фона и не сливались с ним. Рамки карточек: `#1A1A1F` / `#222228`.
3. **БЕЛЫЙ `#FFFFFF`**:
   - Основной текст, главные заголовки, важные цифры и активные элементы.
   - Базовое состояние ключевых кнопок (например, «УСТАНОВИТЬ РАСШИРЕНИЕ»): белый фон `#FFFFFF` с чёрным текстом `#000000`.
4. **СЕРЫЙ ТЕКСТ `#929292`** — Второстепенный текст под основным белым заголовком (описания, мелкие пояснения, даты, метаданные, неактивные надписи).
5. **ОРАНЖЕВЫЙ `#FF5500` (АКЦЕНТ НАВЕДЕНИЯ / HOVER)**:
   - Используется СТРОГО при наведении (`:hover`) на интерактивные объекты.
   - Когда пользователь наводит курсор на белую кнопку — она заливается цветом `#FF5500`, чтобы было очевидно взаимодействие.
   - Статично использовать оранжевый цвет ЗАПРЕЩЕНО (только hover, активный выбор вкладки или явное отдельное указание).

---

### СТРОГИЕ ЗАПРЕТЫ:
- **КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО** использовать любые синие, синеватые (`slate`, `zinc`), зелёные, красные, фиолетовые или градиентные оттенки в интерфейсе без прямого указания.
- **Все скругления на кнопках, карточках и элементах интерфейса**: строго прямые углы (`rounded-none` / `border-radius: 0px !important`).
- **Единый шрифт**: системный стек шрифтов Apple (`-apple-system, BlinkMacSystemFont, "SF Pro Text", "SF Pro Display", "SF Pro", "Segoe UI", Roboto, Helvetica, Arial, sans-serif !important`).

### ТАКСОНОМИЯ ТОКЕНОВ В TAILWIND:
```javascript
// tailwind.config.js
module.exports = {
  theme: {
    extend: {
      colors: {
        brand: {
          bg: '#000000',
          card: '#090909',
          border: '#1A1A1F',
          text: '#FFFFFF',
          muted: '#929292',
          accent: '#FF5500'
        }
      }
    }
  }
}
```
