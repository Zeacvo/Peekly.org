# LOCAL-FIRST MCP WORKFLOW RULES

## 1. Локальный запуск (Мгновенно):
- Все изменения проверяются СТРОГО на локальном dev-сервере (`http://localhost:5173`).
- Если локальный сервер не запущен — поднимать его в фоновом процессе: `npm run dev`.

## 2. Проверка через Chrome DevTools MCP на localhost:
- Инспекция DOM, снятие стилей через `evaluate_script`, клики, проверки роутинга и скриншоты через `take_screenshot` выполнять ИСКЛЮЧИТЕЛЬНО на `http://localhost:5173/...`.
- Это занимает 1–2 секунды вместо 5–7 минут ожидания облачного деплоя.

## 3. Финальная публикация на Cloudflare (Строго один раз в конце):
- Только ПОСЛЕ того, как все задачи полностью решены, проверены на `localhost` и сняты подтверждающие скриншоты:
  1. Проверить локальную сборку: `npm test && npm run build`.
  2. Зафиксировать коммит и отправить в репозиторий:
     ```bash
     git add .
     git commit -m "<type>(scope): description"
     git push origin main
     ```
  3. Не зависать в блокирующих таймерах ожидания Cloudflare Pages. Как только код отправлен в `origin main` — отчитаться о выполнении задачи, приложив локальные скриншоты верификации.
